# أطلب - Etlob

منصة إعلانات مبوبة للسعودية — clone of Mourjan/Marjan.

## المميزات
- تسجيل دخول وإنشاء حساب مع صورة شخصية ورقم جوال
- إضافة إعلانات مع صور متعددة ونص عربي/إنجليزي
- تصفح الإعلانات مع فلتر جانبي متقدم
- صفحة ملف شخصي مع تبويبات (إعلانات فعالة، قيد الانتظار، مسودات، أرشيف)
- تميز الإعلان، إيقاف العرض، تعديل
- عداد مشاهدة لكل إعلان
- واجهة عربية كاملة (RTL)

## التقنيات
- Python 3.12
- Django 6.0.6
- SQLite
- HTML/CSS/JS

## التشغيل
```bash
cd app
pip install -r ../requirements.txt
python manage.py migrate
python manage.py runserver 0.0.0.0:8000
```
